# My-Portfolio1

A front-end portfolio project: a **News & Magazine** website built from a Figma design.

🎨 **Design:** [View on Figma](https://www.figma.com/design/65wYP3DzqMjQ29P3QAyX0g/News-and-Magazina-website--Community-?node-id=103-48&t=jol3TiNzVZvD355M-0)

🌐 **Live Demo:** https://AbbasiAli2777.github.io/My-Portfolio1/

## Pages
- Homepage
- Blogs and Blog details
- Category
- Features
- Contact
- Login / Create Account (with active and error states)

## Technologies
- HTML5
- CSS3 / SCSS
- Bootstrap 5

## How to run
Clone the repository and open `index.html` in your browser.
